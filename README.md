# SHADOWBAN

Monorepo for the SHADOWBAN multiplayer prototype.

Current implementation status, infrastructure notes, open work, and handoff details live in [docs/project-state.md](docs/project-state.md).

## Common scripts

- `npm install`
- `npm run dev`
- `npm run test`
- `npm run lint`
- `npm run typecheck`
- `npm run prisma:generate`

## Local services

- Client: `http://localhost:5173`
- Server: `http://localhost:3001`
- PostgreSQL: `localhost:5432`
